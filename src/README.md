# Admin Dashboard (React)

A simple admin dashboard built with React.
This project demonstrates authentication, CRUD operations, routing and state management.

---

## Features

- Login system with persistant authentication (localStorage)
- Dashboard with user management (CRUD)
- React router navigation
- Component based architecture
- Controlled forms
- State management using React hooks

---

## Tech Stack

- React
- Vite
- React Router
- JavaScript (ES6)
